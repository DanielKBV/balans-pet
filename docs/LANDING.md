# Лендинг Balans: концепция (RUN 2)

Задача страницы: за 10 секунд показать, что Balans — настоящий работающий продукт, а его автор, Даниэл, делает аккуратно, быстро и не по шаблону. Вкус: Vercel (строгий тёмный, один объёмный элемент), Linear (продукт настоящими экранами, мало текста), Apple (крупный текст, предмет движется при прокрутке). Нельзя: скучно, «ИИшно», вода, неон, лаги, прыгающие элементы.

**Идея страницы — «живой отчёт».** Вся страница собрана из того же, из чего собран кабинет: цифры, столбики, строки записей. Никаких иллюстраций и стоковых картинок: продукт сам себе иллюстрация. Только тёмная тема.

## 3. Идея 3D: «месяцы стоят столбиками»

График доходов и расходов кабинета поднимается в объём. На тёмной плоскости 6 пар столбиков, по одной на месяц демо: зелёный доход, красный расход, пропорции из настоящих данных демо. Над парами тонкая индиго-линия прибыли. Последняя пара (текущий месяц) чуть ярче.

- Загрузка: столбики вырастают из плоскости слева направо, как будто месяцы досчитываются (~1,2 с, один раз).
- Мышь: сцена наклоняется за курсором на 3–4°. Прокрутка: камера медленно опускается, линия прибыли «дорисовывается».
- Простые фигуры кодом, цвета из токенов тёмной темы, без текстур и моделей.

**Статичная картинка (RUN 2 и запасной вариант):** та же сцена в изометрии, нарисованная SVG прямо в коде (ноль запросов, чёткая на любом экране): 6 пар столбиков, линия прибыли, слабое индиго-свечение за ними. Блок с фиксированными пропорциями 4:3, чтобы в RUN 3 canvas встал на её место без сдвига. В RUN 3 камеру ставим так, чтобы первый кадр совпал с картинкой.

**Фон гостевых страниц (Фаза 3)** из того же мотива: несколько полупрозрачных контурных столбиков медленно поднимаются и опускаются по краям экрана, CSS + SVG.
