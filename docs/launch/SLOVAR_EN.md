# Словарь интерфейса RU → EN

Правило: одно действие везде называется одинаково. Слова общепринятые (как в Stripe, Linear, Google), не дословный перевод. Если слова здесь нет, выбери по тому же принципу и добавь строку в этот файл.

## Вход
| Русский | English |
|---|---|
| Войти | Sign in |
| Зарегистрироваться | Sign up |
| Выйти | Sign out |
| Войти через Google | Continue with Google |
| Забыли пароль? | Forgot password? |
| Сбросить пароль | Reset password |
| Новый пароль / Повторите пароль | New password / Confirm password |
| Уже есть аккаунт? Войти | Already have an account? Sign in |
| Нет аккаунта? Зарегистрироваться | Don't have an account? Sign up |
| Проверьте почту | Check your email |

Не смешивать Sign in и Log in.
