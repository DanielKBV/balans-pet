# RUN 3. 3D в главном блоке: компьютер, телефон, скорость

Сначала загрузи skill `balans-launch` и прочитай `docs/launch/PROGRESS.md`, `docs/LANDING.md`, `docs/DESIGN.md`. Загрузи skills `threejs-react-three-fiber`, `threejs-performance`, `threejs-geometry`, `threejs-materials`, `threejs-lighting`, `react-best-practices`, `core-web-vitals`. Документацию React Three Fiber и drei бери через context7 (или `https://r3f.docs.pmnd.rs/llms.txt`, `https://drei.docs.pmnd.rs/llms.txt`), особенно страницу «Scaling performance». Работай по правилам skill.

## Цель

В главном блоке лендинга появляется 3D-сцена из `docs/LANDING.md`. Она показывает работодателю и заказчику редкое умение: **3D, которое не тормозит и работает на телефоне**. Красивую сцену, из-за которой сайт открывается медленно или греет телефон, здесь считаем провалом: она покажет обратное.

Поэтому порядок такой: страница остаётся такой же быстрой, как после RUN 2, а 3D добавляется сверху и само отступает там, где устройство не тянет.

## Как это должно работать

1. Страница открывается с картинкой сцены (poster). Текст и кнопки доступны сразу.
2. После загрузки страницы, когда браузер свободен и главный блок на экране, подгружается отдельный чанк со сценой. Canvas плавно проявляется поверх картинки. Страница при этом не прыгает.
3. Сцена следит за FPS и переключает ступени качества (чёткость, число объектов, тени, эффекты). Используй штатные средства R3F и drei для этого.
4. Картинка остаётся вместо 3D, если: включено «уменьшить движение», нет WebGL, включена экономия трафика, устройство слабое, сцена не удержала FPS даже на нижней ступени, потерян контекст WebGL, или `NEXT_PUBLIC_HERO_3D=off`.
5. Когда сцена ушла за экран или вкладка скрыта, кадры не рисуются.

## Требования к сцене

- Библиотеки: `three`, `@react-three/fiber`, `@react-three/drei` версий, совместимых с React и Next в проекте (проверь в `package.json` и документации). Других 3D-библиотек и тяжёлых эффектов не ставить.
- Геометрия кодом, из простых фигур, повторы через instancing. Без загружаемых моделей и текстур, если концепция этого не требует.
- Лендинг только тёмный, поэтому сцена делается под тёмную тему. Цвета из токенов. Материалы и свет в рамках маркетингового слоя `DESIGN.md`: сцена выглядит частью Balans.
- Движение спокойное: сборка при появлении, лёгкий отклик на мышь на компьютере. На телефоне без отклика на палец: canvas не перехватывает прокрутку.
- Canvas скрыт от экранного диктора, рядом есть текстовое описание для него.
- Сцена — клиентский компонент, подключается динамически без серверного рендера. Память освобождается при уходе со страницы.
- Картинка-poster снимается с самой сцены (скриншотом через Playwright) чтобы подмена была незаметной.

## Фазы

### Фаза 1. Сцена на компьютере

Ветка `launch/run-3`. Сцена, ленивая загрузка, подмена картинки. Проверка: `check-screens` и `screen-reviewer` на 1024, 1440, 1920; сцена смотрится цельно с текстом главного блока.

### Фаза 2. Телефон и запасные варианты

Ступени качества, пауза вне экрана, все случаи из пункта 4, выключатель. Вёрстка главного блока на 360, 390, 768: сцена не закрывает текст и кнопку.

### Фаза 3. Скорость

Вызови `perf-auditor`. Сравни с замером RUN 2 из `PROGRESS.md`. Цель: бюджет выполнен, Performance упал не больше чем на 3 пункта относительно RUN 2, чанк three.js не грузится на первом экране, LCP-элемент не canvas.

Если бюджет не выполнен: исправляй по причинам из отчёта и меряй снова. Не больше 3 кругов. Если после третьего круга бюджет на телефоне всё ещё не выполнен, упрости сцену для телефона или оставь на телефоне картинку, и честно напиши об этом в отчёте. Скорость важнее 3D.

Запиши в `docs/LANDING.md` короткий раздел «Как устроено 3D и почему оно быстрое» простыми словами: Даниэл будет рассказывать это на собеседовании и может вставить в описание проекта.

### СТОП

Полные ворота, push, preview-ссылка. Отчёт по формату с таблицей замеров «до / после».

Даниэлу, на своём телефоне по preview-ссылке:
1. Страница открылась быстро, сначала картинка, потом 3D без рывка.
2. Прокрутка пальцем через главный блок плавная.
3. Через минуту на странице телефон не греется.
4. Включить в настройках телефона «уменьшить движение» (или режим экономии энергии) и обновить: осталась картинка.
5. Оба языка.

После «ок» — влить в `main`. Если что-то из списка плохо, Даниэл пишет, что именно; один круг правок. Если не получается за круг, на боевом сайте включается `NEXT_PUBLIC_HERO_3D=off` для телефонов или целиком, и запуск не задерживается.

## Чего не делать

Не добавлять 3D на другие страницы. Не ставить постобработку ради красоты, если она не укладывается в бюджет. Не менять тексты и структуру лендинга. Не трогать кабинет.
