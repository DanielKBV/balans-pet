# Дизайн-система Balans

Единые правила для каждого экрана Balans. Все значения живут как токены в `src/app/globals.css`. Живая витрина: страница `/design`.

**Главное правило:** любой интерфейс делается только по этому документу и токенам темы. Цвета, размеры, тени и скругления «на глаз» (`#5b5bd6`, `text-[15px]`, `shadow-[...]`) в компонентах запрещены. Если нужного токена или компонента нет, сначала добавляем его сюда и в `globals.css`, потом используем.

---

## 1. Откуда стиль

Брали **стиль**, а не бренд: чужих логотипов, фирменных цветов один в один и названий нет.

| Образец | Что взяли | Что не взяли |
|---|---|---|
| **Stripe Dashboard** | Индиго как единственный цвет действия. Деньги: крупная цифра, под ней серая подпись, рядом изменение в процентах. Цифры одинаковой ширины (`tnum`). Таблица без зебры, тонкие разделители, суммы справа. Глубина за счёт оттенка фона, а не тени | Их `#533afd` один в один, тонкий вес 300 для заголовков (на кириллице читается хуже), скругления 4 px, платный шрифт Söhne |
| **Linear** | Тёмная тема с холодным оттенком, слои поверхности отличаются светлотой. Меню слева ~240 px. Текст 16 px / 1.5, сдержанные заголовки со сжатым трекингом. Карточки 12 px, кнопки и поля 6–8 px. Без весов 700+, без теней у карточек, без градиентов | Кислотно-лимонную кнопку, почти чёрный фон `#08090a` (слишком контрастно для долгого чтения цифр), командную палитру ⌘K (в «Версию 2») |
| **shadcn/ui, dashboard-01** | Техническая основа: CSS-переменные, oklch, `@theme inline`, тёмная тема классом `.dark`, компоненты Card / Table / Badge / Dialog / Sonner / Skeleton / Chart. Раскладка: меню слева, карточки с цифрами, график, таблица | Чёрно-белый `--primary`, серые цвета графиков, тени на карточках |

## 2. Анти-правила: Balans не должен выглядеть «сделанным ИИ»

Запрещено:

- **градиенты**, особенно фиолетовые, свечение (glow), стекло и размытие фона (`backdrop-blur`). **Единственное исключение:** лёгкое размытие (`backdrop-blur-sm`, 8 px) под открытым диалогом, чтобы внимание было на окне, а не на странице за ним;
- **эмодзи** в интерфейсе;
- **иконки в цветных кружках** у каждой карточки;
- **одинаковые сетки из 3 карточек** «преимуществ»;
- **большие тени** и **скругления больше 16 px**;
- **пустые маркетинговые фразы** («Революционный способ управлять финансами»). Пишем конкретно: «Выручка за октябрь», «Записей пока нет, добавьте первую».

И ещё:

- Индиго **глубокий и сдержанный** (`oklch(0.47 0.16 277)`), не ярко-фиолетовый.
- **Цвет только там, где он что-то значит:** действие (индиго), доход (зелёный), расход (красный), ошибка (красный), предупреждение (янтарный). Всё остальное в оттенках серого.
- Иконки lucide нейтрального цвета (`text-muted-foreground`), 16–20 px, без подложек.
- Насыщенность шрифта не выше 600.

## 3. Цвета

Формат oklch: L (светлота) C (насыщенность) H (оттенок). Почему oklch: одинаковое L даёт одинаковую видимую светлоту, поэтому пары для светлой и тёмной темы подбираются предсказуемо. Шаблон shadcn уже на oklch.

Контраст каждой пары проверен скриптом по формуле WCAG 2.1. Порог 4.5:1 для текста, 3:1 для границ полей и рамки фокуса.

### Поверхности и текст

| Токен | Для чего | Светлая | Тёмная |
|---|---|---|---|
| `background` | Фон страницы | `#F6F7F9` | `#0E0F12` |
| `card` | Карточки, таблицы, поля | `#FFFFFF` | `#16171A` |
| `popover` | Меню, диалоги, уведомления | `#FFFFFF` | `#1B1D21` |
| `muted` | Скелетоны, подложки, наведение | `#EFF0F3` | `#202225` |
| `foreground` | Основной текст | `#141822`: 17.7 на карточке | `#EDEEF1`: 15.5 |
| `muted-foreground` | Второстепенный: подписи, даты | `#565B65`: 6.8 | `#A4A8AF`: 7.5 |
| `subtle-foreground` | Приглушённый: плейсхолдеры, неважное | `#676C75`: 4.9 на фоне | `#8B8F97`: 5.5 |
| `border` | Границы карточек, разделители | `#E1E3E6` | `#27292C` |
| `input` | Граница поля ввода | `#8F9299`: 3.1 | `#67696F`: 3.25 |
| `ring` | Рамка фокуса с клавиатуры | `#5D63CD`: 5.1 | `#838EED`: 6.0 |
| `overlay` | Затемнение под диалогом (вместе с лёгким размытием) | чернила 24% | чёрный 50% |

**Почему фон серый, а карточки белые:** так делает Stripe. Карточка отделяется от фона без тени, только оттенком и тонкой границей. В тёмной теме наоборот: карточка светлее фона, как слои в Linear. Тень на тёмном фоне не видна.

**Почему не чисто белый и не чисто чёрный текст:** чуть синеватый тёмно-серый `#141822` мягче для глаз. Контраст при этом 17:1, далеко за порогом.

### Акцент (действие)

| Токен | Для чего | Светлая | Тёмная |
|---|---|---|---|
| `primary` | Фон главной кнопки, активный пункт меню, логотип | `#484BB2`: белый текст 7.2 | `#5E65C7`: белый текст 5.05 |
| `primary-hover` | Наведение на главную кнопку | `#3C3E9C` | `#5056B6` |
| `primary-subtle` | Подложка выбранного пункта меню | `#EAEDFF` | `#20243F` |
| `primary-text` | Ссылки и индиго-текст на поверхности | `#484BB2`: 7.2 | `#99A4F0`: 7.6 |

**Почему отдельный `primary-text`:** в тёмной теме кнопке нужен тёмный индиго (иначе белый текст на нём нечитаем), а ссылке на тёмном фоне наоборот светлый. Один цвет не может быть и тем и другим.

**Почему наведение темнее, а не прозрачнее:** у shadcn по умолчанию `bg-primary/80`, и сквозь кнопку просвечивает фон. Отдельный цвет даёт предсказуемый контраст.

### Деньги и статусы

| Токен | Для чего | Светлая | Тёмная |
|---|---|---|---|
| `income` / `income-subtle` | Текст суммы дохода / фон бейджа | `#0B7643`: 5.7 | `#65C98C`: 8.8 |
| `expense` / `expense-subtle` | Текст суммы расхода / фон бейджа | `#B63132`: 6.0 | `#EF7E7C`: 6.8 |
| `warning` / `warning-subtle` | Предупреждение | `#975C16`: 5.4 | `#E6B55D`: 9.5 |
| `destructive` | Фон опасной кнопки | `#BE2323`: белый 6.1 | `#C9302D`: белый 5.3 |
| `destructive-text` / `destructive-subtle` | Текст ошибки / фон блока ошибки | `#BE2323` | `#F2716C`: 6.3 |

**Доход и расход никогда не передаются только цветом.** Рядом всегда знак (`+16 000 сом` / `−45 000 сом`) или подпись («Доход» / «Расход»). Около 8% мужчин плохо различают красный и зелёный.

**Ошибка и расход — оба красные, но разные токены.** Это разные смыслы: расход — нормальная часть жизни бизнеса, ошибка — сбой. Если позже захотим сделать расход менее тревожным, поменяем один токен.

## 4. Цвета графиков

| Токен | Что | Светлая | Тёмная |
|---|---|---|---|
| `chart-income` | Доход | `#3FB171` | `#37AB6B` |
| `chart-expense` | Расход | `#B02A2D` | `#BD373F` |
| `chart-profit` | Прибыль | `#484BB2` | `#6C76D2` |
| `chart-1…6` | Категории, строго в этом порядке | синий, янтарный, фиолетовый, бирюзовый, оранжевый, малиновый | те же оттенки, светлее |
| `chart-other` | «Прочее» | серый | серый |
| `chart-grid` | Линии сетки | почти фон | почти фон |

Как проверено: валидатором палитры (OKLab ΔE, симуляция протанопии, дейтеранопии и тританопии):

- **Доход / расход:** у зелёного и красного одинаковой светлоты при дейтеранопии ΔE всего 3.9, то есть они неразличимы. Поэтому в графиках зелёный светлее (L 0.68), красный темнее (L 0.50). Так они различимы и по яркости: ΔE 16.9 в светлой теме, 11.2 в тёмной.
- **Категории:** соседние пары проходят: ΔE ≥ 7 при дальтонизме, ≥ 15 при нормальном зрении. Порядок подобран так, чтобы похожие пары (бирюзовый и малиновый, синий и фиолетовый) не стояли рядом.
- **Правила:** цвет закрепляется за категорией, а не за местом в рейтинге. Больше 6 категорий: остальные уходят в «Прочее». У каждого графика с двумя и более рядами есть легенда. Подписи и значения пишутся цветом текста, а не цветом ряда. Одна ось Y, никогда две.
- Светлый янтарный (`chart-2`) на белом даёт контраст 2.5:1, поэтому у графиков категорий всегда есть подписи значений или таблица.

## 5. Типографика

**Шрифт: Geist**, подключён через `next/font/google`, наборы `latin` и `cyrillic`, переменная ширина 100–900.

Почему Geist: сравнили на образце кириллицы Onest, Inter и Geist (скриншот в `.screenshots/fonts-specimen.png`, генерируется локально).

- Onest лучше всех рисует кириллицу, но в режиме цифр одинаковой ширины у единицы большие пустоты: «111 111» выглядит разреженно.
- Inter самый широкий: строки переносятся раньше, таблица выходит выше.
- Geist компактный, строгий, ровные цифры в таблицах. Ближе всех к Linear.

**Цифры одинаковой ширины** (`font-variant-numeric: tabular-nums`, класс `tabular-nums`) у всех денег, в таблицах (включено глобально для `<table>`) и в `text-display`. Так столбцы сумм стоят ровно.

### Шкала

| Класс | Для чего | Телефон | Компьютер (от 768 px) | Насыщенность |
|---|---|---|---|---|
| `text-display` | Крупная цифра в карточке | 28 / 1.15 | 36 / 1.1 | 600, tabular |
| `text-title` | Заголовок страницы | 24 / 1.25 | 28 / 1.2 | 600 |
| `text-heading` | Заголовок блока | 20 / 1.4 | 20 / 1.4 | 600 |
| `text-body` | Основной текст, таблицы, формы, меню | 16 / 1.5 | 16 / 1.5 | 400, акцент 500 |
| `text-small` | Подписи под цифрами, даты в таблице | 14 / 1.43 | 14 / 1.43 | 400 |
| `text-axis` | Подписи осей графиков, **только здесь** | 13 / 1.3 | 13 / 1.3 | 400 |

**Почему основной текст 16 px, а не 14 px, как у shadcn:** 14 px по умолчанию — главный признак «типового сгенерированного дашборда». Владелец автомойки читает цифры вечером с телефона, а 16 px заодно спасает от приближения страницы в iPhone при вводе в поле. Ниже 14 px только оси графиков: они вторичны, и места там мало.

**Заголовки:** немного сжатый межбуквенный интервал (−0.01…−0.02 em), как у Linear и Stripe: крупный текст с обычным интервалом выглядит рыхлым. Вес 600, не 700: жирнее на кириллице выглядит грубо.

**Формат денег:** `16 000 сом`. Целые числа, неразрывный пробел между тысячами, перед «сом» тоже неразрывный пробел. Знак минус: «−» (U+2212), не дефис. Всё через функцию `formatSom()`, вручную суммы не форматируем.

## 6. Скругления

Базовая величина `--radius: 8px`, остальное производное. **Больше 16 px не бывает:** `rounded-3xl` и `rounded-4xl` тоже равны 16 px, чтобы случайно не нарушить правило.

| Класс | Размер | Где |
|---|---|---|
| `rounded-sm` | 4 px | Мелкие внутренние элементы, полоски графиков |
| `rounded-md` | 6 px | Бейджи |
| `rounded-lg` | 8 px | Кнопки, поля, пункты меню, логотип |
| `rounded-xl` | 12 px | Карточки, блок таблицы |
| `rounded-2xl` | 16 px | Диалоги |

Почему 8 / 12: Linear использует 6 / 12, Stripe 4 / 4. 4 px выглядит строго-бухгалтерски, 12+ на кнопках — игрушечно. 8 px на кнопке высотой 40–44 px смотрится собранно.

## 7. Отступы и сетка

- **Шаг 4 px** (шкала Tailwind: `1` = 4 px). Основные: 8 (между элементами), 16 (внутри карточки на телефоне), 24 (внутри карточки на компьютере, между блоками), 32 (между секциями).
- **Контейнер страницы** `page-container`: максимум **1280 px** по центру. Боковые отступы **16 px** на телефоне, **24 px** с 768 px, **32 px** с 1024 px. На 1920 px содержимое не растягивается: длинные строки таблиц и широкие графики хуже читаются.
- **Меню слева** `w-sidebar` = **240 px**, видно с 1024 px. Уже 1024 px вместо него **нижнее меню** `h-bottom-nav` = 64 px плюс отступ под системную полосу iPhone (`env(safe-area-inset-bottom)`).
- **Шапка** `h-header` = 56 px.
- **Размер управляющих элементов** `h-control`: **44 px на телефоне, 40 px с 768 px**. Кнопки, поля, переключатели. 44 px — минимум Apple для попадания пальцем.
- **Строки таблиц и пункты меню**: не ниже **40 px** (`min-h-row`).

## 8. Тени и границы

| Что | Как отделяется |
|---|---|
| Карточки, таблицы, поля, меню слева | **Только граница 1 px** `border-border`, без тени |
| Выпадающие меню, подсказки, уведомления | Граница + маленькая тень `shadow-popover` |
| Диалог | Граница + тень `shadow-dialog` + затемнение и лёгкое размытие фона |

Почему так: тень сообщает «этот слой над остальными». Если тень у всего, она ничего не сообщает. Карточки лежат на странице, поэтому им хватает границы. В тёмной теме тени почти не видны, поэтому там слои различаются светлотой поверхности: фон → карточка → всплывающее окно.

## 9. Анимации

| Что | Длительность | Плавность |
|---|---|---|
| Наведение, нажатие, смена цвета | 120 мс (по умолчанию для `transition`) | `ease-standard` = `cubic-bezier(0.2, 0, 0, 1)` |
| Открытие меню, диалога, уведомления | 150–200 мс, затухание + лёгкое масштабирование 0.96 → 1 | та же |
| Закрытие | 100–150 мс | та же |

- Никаких пружин, отскоков, бесконечных пульсаций. Только CSS (`tw-animate-css` уже идёт с shadcn), без библиотек анимаций.
- **«Уменьшить движение»** (`prefers-reduced-motion: reduce`): все анимации и переходы глобально сокращаются почти до нуля. Интерфейс работает так же, просто без движения.
- Почему коротко: это рабочий инструмент, его открывают каждый день. Анимация длиннее 200 мс на сотый раз раздражает.

## 10. Состояния

| Состояние | Как выглядит |
|---|---|
| Наведение | Главная кнопка: `primary-hover`. Остальные: подложка `accent`. Строка таблицы: `muted/50` |
| Нажатие | Сдвиг на 1 px вниз (`translate-y-px`) |
| Фокус с клавиатуры | Рамка `ring` 3 px полупрозрачная + граница `ring`. Только `focus-visible`: мышью рамка не появляется |
| Неактивно | Прозрачность 50%, клики выключены |
| Ошибка поля | Граница `destructive`, под полем текст ошибки `text-small text-destructive-text`, `aria-invalid` |
| Загрузка | Скелетоны `bg-muted` той же формы, что и содержимое. Не спиннер на весь экран |
| Пусто | Иконка lucide (серая, без кружка), заголовок, одна фраза, одна кнопка действия. «Записей пока нет, добавьте первую» |
| Ошибка загрузки | Иконка, понятный текст («Не удалось загрузить записи. Проверьте интернет»), кнопка «Повторить» |

Каждый список и график показывает все три: загрузка, пусто, ошибка.

## 12. Как добавлять новое

1. Нужен цвет, размер или тень, которого нет: добавить токен в `globals.css` для **обеих** тем.
2. Проверить контраст (текст ≥ 4.5, граница поля и фокус ≥ 3).
3. Записать в этот документ с объяснением «почему».
4. Показать на `/design`.
5. Только потом использовать на странице продукта.
