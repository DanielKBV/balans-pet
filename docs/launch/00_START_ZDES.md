# Balans: запуск для портфолио. Начни здесь

Четыре запуска вместо девяти этапов. Каждый запуск Claude Code ведёт сам: идёт по фазам, после каждой сам себя проверяет, останавливается только там, где нужен ты.

## План по дням

| Когда | Что | Твоё время | После этого |
|---|---|---|---|
| Вс, сейчас | Шаг 0: инструменты (`01_INSTRUMENTY.md`) и заполнить `MOI_DANNYE.md` | 30 мин | Всё готово к работе |
| Вс | **RUN 1.** Английский язык и ключевые ошибки | 2 остановки | Весь продукт на двух языках |
| Пн, утро | **RUN 2.** Новый лендинг, фон на страницах входа, ссылки | 2 остановки | **Сайт уже можно показывать** |
| Пн, день | **RUN 3.** 3D: компьютер, телефон, скорость | 1 остановка | Лендинг с 3D |
| Пн вечер или Вт утро | **RUN 4.** Превью ссылок, SEO, README, финальная проверка | 1 остановка | Ссылка в резюме |

Если во вторник 3D ещё не готово, запускай RUN 4 сразу после RUN 2 и ставь проект в резюме. 3D доделаешь после: лендинг из RUN 2 уже законченный, с картинкой на месте сцены.

## Как запускать

1. Сделай шаг 0 из `01_INSTRUMENTY.md`.
2. Заполни `docs/launch/MOI_DANNYE.md` в проекте: ссылки и 2–3 сайта, которые тебе нравятся. Это нужно, чтобы лендинг понравился с первого раза.
3. Для каждого запуска открой **новую** сессию Claude Code (или `/clear`), выбери Fable 5.2, включи автоприём правок (Shift+Tab) и вставь одну строку:

```
Загрузи skill balans-launch и выполни docs/launch/RUN_1_yazyk_i_oshibki.md
```

Дальше по очереди:

```
Загрузи skill balans-launch и выполни docs/launch/RUN_2_lending.md
Загрузи skill balans-launch и выполни docs/launch/RUN_3_3d.md
Загрузи skill balans-launch и выполни docs/launch/RUN_4_seo_i_final.md
```

4. Если сессия оборвалась или кончился контекст, открой новую и напиши: `Загрузи skill balans-launch, прочитай docs/launch/PROGRESS.md и продолжи RUN N с того места, где остановился`.

## Что такое остановка (СТОП)

Claude Code сам пишет: что сделал, чем доказал, **что сделать тебе** по шагам. Обычно это открыть preview-ссылку на телефоне и ответить «ок». Дважды нужно зайти в Supabase (RUN 1: применить миграцию и вставить письма).

Работа идёт в отдельной ветке, боевой сайт меняется только после твоего «ок». Сломать работающий сайт в процессе нельзя.

## Что я решил за тебя, чтобы успеть

- **Язык через cookie, без `/ru` и `/en` в адресе.** Раньше я советовал адреса, но при сроке 2 дня это самый рискованный кусок: пришлось бы переносить все страницы и перекраивать вход. На Upwork даёшь ссылку `balans-pet.vercel.app/?lang=en`, она включает английский.
- **`/admin` и `/design` остаются на русском.**
- **3D на телефоне:** облегчённое, с автоматической заменой на картинку. Есть выключатель, если на твоём телефоне будет плохо.
- **Фон на страницах входа:** CSS и SVG, без 3D, чтобы не тормозило.
- **Одна идея 3D** (столбики доходов и расходов). Ты утверждаешь её в начале RUN 2.

Всё, что не вошло, записано в `PROGRESS.md` в раздел «После запуска».

## Правило на эти два дня

На остановке отвечай «ок» или называй **конкретную** правку. Не «давай ещё варианты». Один круг правок на остановку, потом дальше. Новые идеи говори Claude Code словами «запиши в после запуска».
